# lyricsQ

## Spotify 歌词 for macOS

lyricsQ 是一个面向 macOS Spotify Desktop 的原生歌词应用：跟随当前播放歌曲和进度，提供主播放页、桌面歌词、全屏歌词、歌词库和本地歌词编辑。

> **当前预览状态（2026-09-07）**
>
> 本页按真实预览中的功能状态编写。界面里存在的按钮不等于功能已经可用；明确标为 **Bug / 当前不可用** 的功能不要当作稳定能力使用。
>

## 功能总览

### ✅ 当前可用

| 区域 | 功能 | 说明 |
| --- | --- | --- |
| 播放同步 | Spotify Desktop 当前歌曲、艺人、专辑、播放状态和进度 | 跟随当前 Spotify 播放上下文 |
| 播放控制 | 播放/暂停、上一首、下一首、进度拖动 | 不修改 Spotify 原始播放数据 |
| 菜单栏 Quick Glance | 封面、歌曲信息和基础播放控制 | 使用 macOS 菜单栏入口 |
| 主播放页 V3 | 环境光、经典、舞台三种布局 | 横屏、竖屏、自由缩放和完整封面适配 |
| 主播放页歌词 | 原文、当前行、逐字高亮、假名、罗马音、翻译 | 各图层可独立显示或隐藏 |
| 歌词工具栏 | 歌词版本、歌词显示、外观背景、歌词时间 | 当前歌曲和当前歌词版本共用同一个时间偏移 |
| 歌词搜索与恢复 | 按当前歌曲身份查找、选择和恢复候选歌词 | 保留来源和版本 provenance，不强制覆盖 |
| 歌词复制 | 右键复制当前行、整首歌词、选择段落 | 右键歌名/歌手也可复制元数据 |
| 歌词时间 | 提前、延后、直接输入、恢复默认 | 只影响歌词呈现，不改变 Spotify 播放进度 |
| 桌面歌词 | 独立悬浮歌词窗口 | 单行/双行、字体、字号、颜色、透明度、描边、图层选择 |
| 桌面歌词交互 | 穿透/交互模式、歌词复制、当前行同步 | 穿透锁定后可恢复交互 |
| 全屏歌词 | 原生全屏歌词窗口 | 按样式保存歌词位置、对齐和阅读字号 |
| 歌词库 | 保存、选择和管理多个歌词版本 | 原始版本与本地修订版本分开保留 |
| 歌词导入 | TXT、LRC、剪贴板纯文本和翻译文本导入 | 导入前预览，尽量保留原始内容 |
| 歌词编辑 | 修改原文、翻译、假名、时间、顺序 | 支持拆分、合并、移动、单行时间编辑和修订版本 |
| 版本导出 | 导出原文、翻译和歌词版本 | 不覆盖原始歌词版本 |
| 日语辅助 | 假名、罗马音、上下文读音和歌曲级纠音 | 手动纠音会保存为歌曲范围内的新版本 |
| 最近播放 | 记录本地观察到的播放会话 | 循环播放会形成多条独立观测记录 |
| 听歌统计 | 播放时长、播放记录、歌曲排行和趋势 | 只代表 lyricsQ 本地观察结果，不是 Spotify 完整历史 |
| 歌词来源 | 本地/SQLite、AMLL、LRCLIB、lyrics.ovh | 不同候选独立保存，默认不覆盖用户版本 |

### ⚠️ 可用但受来源或环境限制

- AMLL、LRCLIB、lyrics.ovh、Kuwo、Kugou、网易云和 QQ 音乐的命中率、时间轴、翻译质量取决于歌曲元数据、录音版本和第三方服务状态。
- Kuwo、Kugou、网易云和 QQ 音乐属于实验网络来源，可能请求失败、返回近似录音，或只提供部分图层；切换前应核对歌曲版本。
- 歌词本身如果逐行时间轴不准，统一“提前/延后”只能校正整体偏差，不能修复每一行都不同的时间误差。
- 日语假名和罗马音在姓名、罕见词、多音词上仍可能需要手动纠正。
- 最近播放和听歌统计是本地观测数据；暂停、外部切歌、应用未运行期间不会被还原成完整 Spotify 历史。

## 歌词来源和版本策略

lyricsQ 会先读取本地保存的歌词版本，再按设置搜索在线来源。不同来源、不同录音版本和用户修订版本会作为独立候选保留：

- 不自动覆盖已保存或已编辑的歌词。
- 显示来源、版本和可用图层，便于切换试听。
- `Piano Ver.`、现场版、Remix 等录音版本优先按曲目身份和时长区分；匹配不确定时保留候选，不强行替换。
- 原始歌词时间戳不因歌词时间偏移而改变；偏移只属于当前歌曲 + 当前歌词版本的呈现设置。

## 运行要求

- macOS 14 或更高版本
- Spotify Desktop
- Xcode（从源码构建时）

## 从源码运行

```sh
git clone https://github.com/suifracti/lyricsQ.git
cd lyricsQ
open SpotifyLyrics.xcodeproj
```

也可以直接构建 Debug 版本：

```sh
xcodebuild -project SpotifyLyrics.xcodeproj \
  -scheme SpotifyLyrics \
  -configuration Debug \
  -derivedDataPath /tmp/lyricsq-deriveddata \
  CODE_SIGNING_ALLOWED=NO build
```

涉及 ScreenCaptureKit 或本机权限的调试可能需要本地开发签名。个人 Team ID、证书和其他凭据不应提交到仓库。

## 数据与隐私

- 歌词、编辑版本、历史和统计默认保存在 `~/Library/Application Support/SpotifyLyrics/SpotifyLyrics.sqlite3`。
- Spotify 授权令牌和用户填写的 AI API Key 使用 macOS Keychain；仓库不包含可用凭据。
- 使用在线歌词来源时，匹配歌曲所需的标题、艺人、专辑、时长或曲目 ID 会发送给对应服务。
- 使用 AI 翻译功能时，歌词文本会发送给用户配置的服务端点；但该功能在当前预览中标记为 Bug/不可用。
- 自动排轴若恢复开发，可能需要屏幕录制或系统音频权限；当前预览中不要依赖该功能。

## 测试与开发边界

仓库在 `Tests/` 下使用按模块划分的合同脚本。文档和截图变更不需要重新构建应用；功能代码变更时应运行对应合同与 Debug 构建。基础入口为：

```sh
bash Tests/v3_lyric_readability_contract.sh
```

开发边界见 [`docs/DEVELOPMENT_WORKFLOW.md`](docs/DEVELOPMENT_WORKFLOW.md)。正式脏工作区 `/Users/apple/backup/sptifylyrics` 不属于本预览源树，不应被覆盖。
